# 胡希恕剂量思维与方剂条辨框架

> 提取自胡希恕《伤寒论》与《金匮要略》讲座完整讲稿

## 一、剂量思维模型

### 1. 一两折三钱换算公式

**胡希恕的换算标准**：汉一两 ≈ 三钱 ≈ 9克（约数，非精确）

**原文**：多处明确说"一两合现在三钱"

**实际操作中的剂量范围**：
| 药物 | 常用量 | 最大量 | 说明 |
|------|--------|--------|------|
| 桂枝 | 9-12g（三两=四钱） | 15g | 解表常规 |
| 麻黄 | 6-9g（二两=三钱） | 12g | 小发汗即可 |
| 大黄 | 6-10g（二两=三钱） | 15g | "6g就蛮好" |
| 附子 | 3-9g（一枚=三钱） | 15g(通脉四逆) | 随证加重 |
| 干姜 | 4-9g（一两半=钱半） | 15g(通脉四逆) | 随证加重 |
| 石膏 | 30-60g（半斤=八两） | 120g | 清热重剂 |
| 细辛 | 3-6g（二两=三钱） | 6g | 不可过量 |

**原文支撑**："我们大黄顶多用10g，三钱，事实上6g效果就满好，绝坏不了事，你要是照这个份量用可是成问题的。一次9钱，就是27克，太重一些。"

### 2. 小剂量原则

**公式**：津液虚 + 汗吐下 → 小剂量微汗 / 小和之

**原文支撑**（第387条）：
"'小和之'，这语气也很含蓄，就是我们用桂枝汤也用小剂量，不要用大量。因为体液丧失太多了，就是发汗也是微似有汗就可以了。"

### 3. 质疑古方超大剂量

胡希恕对古方中某些超大剂量提出质疑：

- **厚朴三物汤用厚朴八两**：胡希恕说"一两合现在三钱，一斤十六两就是四十八钱，一付药二两四，这也够重的"
- **大黄硝石散用大黄四两**：胡希恕说"这太重了，我们不要用得这么重，大黄、硝石各10克就可以了"
- **他用这些话提醒学生**："读古人书你不要死于句下，他这也许是个错误"

### 4. 可变剂量原则（随证/因人调整）

| 调整因素 | 规则 | 例子 |
|---------|------|------|
| 体质强弱 | 强壮者可用常量，虚弱者小剂量 | "小和之" |
| 津液存亡 | 津伤者小剂量微汗 | 第387条 |
| 病情轻重 | 急重→加量，缓轻→常量 | 通脉四逆加大附子干姜 |
| 药性猛烈度 | 峻药（大黄/附子/细辛）→ 起步小量 | "6g就蛮好" |
| 是否初诊 | 先用试探量（小承气试燥屎） | 第209条 |

### 5. 特殊药的重用规则

一些药胡希恕认为可以根据情况重用：

**干地黄可重用**："干地黄还可以多用，这个它应该是六两，这本书上没注份量"

**橘皮可重用**："你开橘皮二两四已经很重的……可是不这样不足以下气、去气塞"

**厚朴枳实**："量用大点没问题"

### 6. 剂量铁律速查

```
常规量：一两≈三钱≈9克（基础换算）
下剂试：大黄→6克起步，不行再加（第209条试探法）
汗剂量：微似有汗即止，不大捂大盖（第12条桂枝汤服法）
温剂量：附子视阳虚程度，轻3-6克/重9-15克
质疑量：超过四两(36克) → 临床慎用，古人可能有误
```

## 二、方剂条辨分析框架（AI 可执行模板）

这是从胡希恕讲解398条条文中提炼出的可重复的条文分析模式。每条条文讲解都遵循这个框架。

### 框架总览：七步条辨法

```
Step 1: 读原文 → 引用条文
Step 2: 解词 → 大白话解释关键术语
Step 3: 辨六经 → 属于哪个经的病
Step 4: 析病机 → 为什么会出现这些症状
Step 5: 辨方证 → 本方 vs 类似方如何区分
Step 6: 指陷阱 → 常见错误理解/错误用法
Step 7: 临床说 → 胡希恕的临床经验/案例
```

### Step 1: 读原文

**操作**：先引用完整的伤寒论/金匮要略原文，作为分析的基础。

**胡希恕常用表述**："这一条说的是……""这段分几节来看……"

### Step 2: 解词——大白话翻译

**操作**：逐词解释关键术语，用生活化语言。这是胡希恕的招牌。

**标准流程**：
```
文言术语 → 医理含义 → 大白话 → 临床所见
```

**实例**：
- "喘家" → 平时就有喘的人
- "几几" → "小鸟学飞时羽毛不丰，脑袋往前伸的样子"  
- "酒客" → "病酒的人"
- "项背强" → "脖子回转不自如"
- "脉缓" → "就像烟卷裹得很紧"（对比紧脉）

### Step 3: 辨六经——六经八纲定位

**操作**：确定此条文中描述的病属于哪个六经，病性如何。

**标准流程**：
```
症状列表 → 对照六经提纲 → 判定病位（表/里/半表半里）+ 病性（阴/阳）
```

**判定口诀**：
| 六经 | 提纲 | 核心证 |
|------|------|--------|
| 太阳 | 脉浮头项强痛恶寒 | 表 + 阳（发热） |
| 阳明 | 胃家实 | 里 + 阳（热实） |
| 少阳 | 口苦咽干目眩 | 半表半里 + 阳 |
| 太阴 | 腹满而吐食不下自利益甚 | 里 + 阴（虚寒） |
| 少阴 | 脉微细但欲寐 | 表 + 阴（无热） |
| 厥阴 | 消渴气上撞心 | 半表半里 + 阴 |

### Step 4: 析病机——为什么出现症状

**操作**：解释症状背后的病理机制。胡希恕的核心分析维度：

| 分析维度 | 关键概念 | 典型问题 |
|---------|---------|---------|
| 正邪交争 | 人体的抗病反应 | 人体想通过什么方式排邪？ |
| 津液存亡 | 胃气→津液→汗/下/利 | 津液从哪丢的？胃气还在？ |
| 水饮瘀血 | 气上冲/停水/瘀血 | 有没有水饮？有没有瘀血？ |
| 表里先后 | 病从哪来，往哪去 | 表未解？传里了？|

**胡希恕常用表述**："所以症状是……其实质是……""古人说……我们现在的理解是……"

### Step 5: 辨方证——本方与类似方鉴别

**操作**：明确本方证的专属指征，同时与最相似的方证做对比。

**标准流程**：
```
本方证核心指征（3-5个）
     vs
类似方A的差别（关键鉴别点）
类似方B的差别（关键鉴别点）
```

**鉴别维度**：有汗/无汗、渴/不渴、脉浮/沉、腹满/不满、手足温/厥、能食/不能食

### Step 6: 指陷阱——常见错误

**操作**：指出中医学界对本条文的常见误解、历代注家的错误、临床容易犯的错。

**错误分类**：
| 错误类型 | 示例 | 胡希恕态度 |
|---------|------|-----------|
| 注家理解错误 | 促脉=数中一止 | "这是错的" |
| 版本错讹 | 脉洪大应为脉浮 | "肯定错了" |
| 王叔和/后人附入 | 欲解时条文 | "照例文章，不可信" |
| 临床误治 | 里热用桂枝汤 | "一定吐，甚至吐脓血" |
| 五行附会 | 阳明少阳合病木克土 | "附会五行家言" |

### Step 7: 临床说——临床经验印证

**操作**：用胡希恕的临床经验/案例来验证或补充条文。这是胡希恕最有特色的环节。

**内容来源**：
- 胡希恕本人的临床案例
- 剂量使用的个人经验
- 对后世用药的评价
- 与西医的对比

## 四、条辨实战示例（用框架分析桂枝汤证）

```
【条文】伤寒论第12条
【原文】太阳中风，阳浮而阴弱。阳浮者，热自发，阴弱者，汗自出。啬啬恶寒，淅淅恶风，翕翕发热，鼻鸣干呕者，桂枝汤主之。
【解词】阳浮阴弱=脉浮于外而弱于内（浮弱）；啬啬=缩缩的样子；淅淅=洒淅怕风的样子；翕翕=合而不开，热都闷在里
【六经定位】病位=表，病性=阳，六经=太阳病
【病机分析】正邪交争在体表，正气想通过发汗排邪，但津气不足以致力不足，汗出邪不去。阳浮=机能亢奋于表（发热），阴弱=津液不足以驱邪（汗出）
【方证要点】汗出+恶风+脉浮弱+发热
【类似方鉴别】vs麻黄汤=无汗（本条有汗），vs桂枝加葛根汤=本条无项背强几几
【常见错误】不能用麻黄汤大发汗（已有汗出，再发则亡津液）；里热不能用（第19条"必吐脓血"）
【胡老临床说】桂枝汤的服法很重要——啜热稀粥助胃气发汗，温覆取微似汗，不可令如水流离。"中医治病是顺应人体的机制"
```
