## 使用示例

**六经辨证**
> **Q**：病人发热恶寒、汗出、恶风、脉浮弱，是什么证？
> **A**：**太阳中风证，桂枝汤证**。发热恶寒→发于阳（三阳）；脉浮+恶寒→表证（太阳）；有汗→中风而非伤寒。综合：太阳病，桂枝汤。条文第13条：太阳病，头痛发热，汗出恶风者，桂枝汤主之。

**方剂鉴别**
> **Q**：大小青龙汤怎么区分？
> **A**：**大青龙汤→不汗出而烦躁（38条）；小青龙汤→心下有水气、咳喘（40条）**。大青龙兼有阳明内热烦躁，小青龙兼有水饮咳喘。一清一化，方向不同。

**阳明病辨证**
> **Q**：大便不通三四天，怎么判断用不用承气汤？
> **A**：**承气三阶递进**。调胃承气→心烦蒸热，无潮热；小承气→腹大满不通，有潮热但未至手足汗出；大承气→潮热+手足濈然汗出+绕脐痛。先用小承气试探：转矢气→有燥屎可攻；无矢气→不可攻。

**死证预后**
> **Q**：下利厥冷无脉，还有救吗？
> **A**：下利厥冷无脉，反微喘→**死证**（362条）。气脱于上，胃气已败。若脉暴出者死，脉微续者可生（315条）。关键在于有无胃气。

## 核心知识体系

### 六经八纲速查表

| 病位 | 阳证（发热恶寒） | 阴证（无热恶寒） |
|------|-----------------|-----------------|
| **表**（体表/肺） | **太阳病**：脉浮、头项强痛、恶寒 | **少阴病**：脉微细、但欲寐 |
| **里**（消化道） | **阳明病**：胃家实、潮热谵语 | **太阴病**：腹满而吐、自利益甚 |
| **半表半里**（胸腹腔间） | **少阳病**：口苦咽干目眩、胸胁苦满 | **厥阴病**：消渴、气上撞心、心中疼热 |

### 胡希恕四大创见

```
1. 六经来自八纲 → 彻底祛魅经络说
2. 方证是辨证的尖端 → 辨证三层次：六经→八纲→方证
3. 正邪交争 → 症状是机体抗病反应，中医顺应而非对抗
4. 胃气为本 → 保胃气存津液，津液存亡定生死
```

### 核心辨证公式

```
辨阴阳： 发热恶寒→阳（三阳） | 无热恶寒→阴（三阴）     [第7条]
辨表里： 脉浮恶寒身痛→表   | 胃家实下利→里         | 非表非里→半表半里
辨寒热： 口中和（不渴）→寒 | 口干渴欲饮→热
辨虚实： 脉有力+声高气粗→实 | 脉无力+声低息微→虚
太阳病： 有汗→桂枝汤证   | 无汗→麻黄汤证         | 项背强几几→桂加葛/葛根汤
阳明病： 心烦蒸热→调胃承气 | 腹满潮热手足汗→大承气
少阳病： 口苦+胸胁满+往来寒热→柴胡证，"但见一证便是"
表里同病： 表为主先解表 | 下利厥冷先救里 | 太阳少阳→柴胡桂枝汤
```
