## 核心特色

### 四大核心心智模型

| 心智模型 | 一句话定义 |
|---------|-----------|
| **六经来自八纲** | 六经不是经络，是「三个病位×阴阳两种证型」的自然分类 |
| **方证是辨证的尖端** | 辨证三层次：六经→八纲→方证，不到方证层面不算辨证完成 |
| **正邪交争** | 所有症状是人体与疾病斗争的产物，中医是顺应人体抗病机制 |
| **胃气为本** | 津液存亡决定生死，胃气是万病之根基 |

## 核心观点速览

### 六经八纲表

| 病位 | 阳证 | 阴证 |
|------|------|------|
| **表** | 太阳病：发热恶寒，脉浮 | 少阴病：无热恶寒，脉微细 |
| **里** | 阳明病：胃家实，潮热谵语 | 太阴病：腹满而吐，自利益甚 |
| **半表半里** | 少阳病：口苦咽干目眩 | 厥阴病：消渴，气上撞心 |

### 辨阴阳公式（第7条）

```
发热恶寒 → 阳证（太阳/阳明/少阳）
无热恶寒 → 阴证（少阴/太阴/厥阴）
```

### 方证鉴别三阶

```
六经（定位）→ 八纲（定性）→ 方证（定方）
```

桂枝汤 vs 麻黄汤：

| 方剂 | 关键指征 | 核心条文 |
|------|---------|:-------:|
| 桂枝汤 | 汗出、恶风、脉浮弱 | 13 |
| 麻黄汤 | 无汗、身痛、脉浮紧 | 35 |

### 常见症状辨证

| 症状 | 辨证思路 |
|------|---------|
| 发热+恶寒→无热恶寒 | 第7条阴阳分水岭 |
| 汗出→无汗 | 桂枝汤 vs 麻黄汤第一刀 |
| 口苦→胸胁苦满→往来寒热 | 柴胡证“但见一证便是” |
| 下利清谷+厥冷 | 四逆辈 |
| 心烦蒸热→潮热→手足汗 | 承气三阶（调胃→小→大） |
